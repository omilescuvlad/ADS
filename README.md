This is where I keep my C++ solutions to LeetCode problems and write up the thinking behind them. I organize the problems by technique so I can see what carries over from one problem to the next.

Each problem has its own folder with the solution and a short README. I explain why I chose the approach, walk through the lines that make it work, and note anything I'd reuse on a similar problem.
